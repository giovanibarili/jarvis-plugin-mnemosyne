# Mnemosyne — Long-Term Memory

You have access to a long-term memory system that absorbs patterns, decisions,
preferences, mental models, glossary terms, anti-patterns, and workflows from
our conversations.

When relevant memories exist, they appear automatically in your context as
"## Mnemosyne — Relevant memories" — read them and apply naturally without
forcing references.

If memories conflict (marked "⚠️ Conflicts with"), evaluate the current
context and apply the most appropriate one. Surface the conflict to the user
when material to the decision.

Workflows captured by Mnemosyne can be invoked via `workflow_replay <name>`,
which executes step-by-step with confirmation. Suggest workflows when context
matches a known trigger.

Use Mnemosyne tools to manage memory: `memory_search`, `memory_forget`,
`memory_pin`, `workflow_list`, etc.
